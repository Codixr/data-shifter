# Changelog

All notable changes to Data Shifter are documented in this file.

## 1.0.0

Initial release.

- Export posts, pages and custom post types to JSON, ZIP (with media), CSV or XML
- Filter exports by status, date range, author and taxonomy term
- Choose fields and custom fields, with optional taxonomies, featured images, galleries and comments
- Import JSON, ZIP, CSV or XML with a drag-and-drop screen and a preview of the first ten items
- Handle existing posts by skipping, updating (matched by title or slug), or always creating new posts
- Chunked uploads and batched imports, with a progress bar and a results summary
- Optional media import and automatic creation of missing categories and tags
